# کافه‌گرد — راهنمای کافه‌ها و رستوران‌های مشهد

راهنمای کافه‌های مشهد با **قیمت واقعی منو**، نقشه‌ی آفلاین، و پنل جدا برای
کاربر، کافه‌دار و مدیر.

| سنجه | مقدار |
| --- | --- |
| مجموعه | **۳۳۱** (۳۲۶ منتشرشده) |
| آیتم منو با قیمت | **۱۹٬۳۸۶** |
| تصویر لوکال | **۱۴٬۴۸۰** (۱٬۰۶۲MB، بدون هیچ CDN بیرونی) |
| عارضه‌ی نقشه | **۷۹٬۵۹۷** از OpenStreetMap، کاملاً آفلاین |
| facet قابل فیلتر | ۳۵ |
| دیش برای «بهترین X نزدیک من» | ۹۸ (۴۲ فعال) |
| تست | **۱۸۵ تست واحد + ۱۳۰ بررسی دود** |

---

## راه‌اندازی

### ۱. پیش‌نیازها

- Node.js ۲۰ یا بالاتر
- MySQL ۸.۰ یا بالاتر با `utf8mb4`

روی این ماشین، MySQL 8.4.11 به‌صورت zip در `C:\mysql` نصب شده و **سرویس
ویندوز نیست**، پس با ری‌استارت بالا نمی‌آید:

```powershell
powershell -File scripts/mysql-service.ps1 start    # بالا آوردن
powershell -File scripts/mysql-service.ps1 status   # وضعیت
powershell -File scripts/mysql-service.ps1 stop     # خاموشی تمیز
```

### ۲. تنظیمات

`.env.local` بسازید (نمونه در `.env.example`):

```ini
DATABASE_URL=mysql://cafegard:رمز@127.0.0.1:3306/cafegard
SESSION_SECRET=<۳۲ بایت تصادفی>
AUTH_DEV_MODE=true            # پیامک ارسال نمی‌شود، کد در ترمینال چاپ می‌شود
SMSIR_API_KEY=…
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

> ⚠️ منطقه‌ی زمانی MySQL **باید UTC باشد** (`default-time-zone='+00:00'`).
> درایور تایم‌استمپ‌ها را UTC می‌خواند؛ اگر سرور روی `+03:30` باشد، همه‌ی
> زمان‌های سایت ۳ ساعت و ۳۰ دقیقه جابه‌جا خوانده می‌شوند. `npm run db:verify`
> این را بررسی می‌کند.

### ۳. ساخت دیتابیس و واردکردن داده

```bash
npm install
npm run db:push          # ساخت جدول‌ها + ایندکس FULLTEXT
npm run media:seed       # ثبت ۱۴٬۵۵۸ آدرس تصویر
npm run media:download   # دانلود و تبدیل به WebP (~۴۵ دقیقه، قابل ازسرگیری)
npm run import:cafes     # واردکردن ۳۳۱ مجموعه
npm run build:facets     # ساخت facet، دیش و رول‌آپ‌ها
npm run map:extract      # استخراج نقشه از PBF (~۷۰ ثانیه)
npm run db:verify        # بررسی نهایی ساختار
```

> ⚠️ `drizzle-kit push` ایندکس‌های FULLTEXT را **بی‌صدا می‌اندازد**. به همین
> دلیل `npm run db:push` خودش `db:extras` را پشت سرش اجرا می‌کند. اگر
> `drizzle-kit push` را دستی زدید، `npm run db:extras` را هم بزنید.

### ۴. اولین مدیر

اولین ادمین را نمی‌شود از داخل سایت ساخت — هیچ ادمینی وجود ندارد که بسازدش:

```bash
npm run user:create -- --phone 09151234567 --role admin --name "نام شما"
```

رمز **یک‌بار** در ترمینال چاپ می‌شود و هیچ‌جا ذخیره نمی‌شود (فقط هشش).
ورود از `/auth` → «ورود با رمز عبور».

### ۵. اجرا

```bash
npm run dev              # توسعه
npm run build && npm start   # تولید
```

> روی ماشین‌های کم‌حافظه (۴GB)، build با `workerThreads: false` و `cpus: 1`
> تک‌فرآیندی اجرا می‌شود — کندتر ولی قابل اتمام. روی سرور با حافظه‌ی بیشتر
> می‌شود این دو را از `next.config.mjs` برداشت.

### قواعدی که در کل کد رعایت شده‌اند

**قیمت نامعلوم `NULL` است، نه صفر.** صفر یک قیمتِ معتبر است (نوشابه در منوی
هتل). ۹۲۸ آیتم قیمت معتبر ندارند و «قیمت روز» نمایش داده می‌شوند. در محاسبه‌ی
باند قیمت هم شرکت نمی‌کنند، وگرنه هر رستورانی که آب‌معدنی صفر تومان دارد
«ارزان» طبقه‌بندی می‌شد.

**«نامشخص» با «ندارد» یکی نیست.** روزی که در ساعت کاری ثبت نشده «تعطیل»
نیست؛ مکانِ بی‌مختصات «دور» نیست. هر جا این تفاوت مهم است، سه‌حالته مدل شده.

**هر نوشتن روی مکان از `core/places/manage.ts` رد می‌شود** تا سه کار با هم
انجام شوند: نوشتن، بازمحاسبه‌ی مقادیر مشتق، ثبت در `audit_log`.

**همه‌ی تایم‌استمپ‌ها UTC.** تبدیل به وقت تهران کارِ لایه‌ی نمایش است.

**مالکیت روی موجودیت بررسی می‌شود، نه روی فرم.** `saveMenuItemAction` شناسه‌ی
مکان را از خودِ آیتم می‌خواند، نه از `placeId` که در فرم آمده.

## نکته‌های عملیاتی

**فایل‌های بزرگ در مخزن نیستند:** `all-cafe-data/` (منبع ۲۱MB + PBF ۲۲۸MB) و
`public/media/` (۱GB) در `.gitignore` هستند. `src/data/map/` (۱۷.۶MB) **در**
مخزن است، چون بازتولیدش به همان PBF نیاز دارد.

**نقشه بدون نام خیابان است.** MapLibre برای متن به گلیف SDF نیاز دارد و
تولیدش وابستگی بومی می‌خواهد؛ ارجاع به CDN بیرونی هم آفلاین‌بودن را نقض
می‌کرد. جهت‌یابی با ۵۱۳ برچسب محله و ۱٬۱۳۱ نقطه‌ی شاخص انجام می‌شود و
مسیریابی به نشان/بلد/گوگل‌مپس واگذار شده. جزئیات:
`task/06-offline-map/REPORT.md`.

**پیامک در حالت توسعه ارسال نمی‌شود.** `AUTH_DEV_MODE=true` کد را در ترمینال
چاپ می‌کند تا اعتبار پیامک نسوزد. برای تولید صریحاً `false` بگذارید.

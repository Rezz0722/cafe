## قرارداد صفحه‌بندی و داده

- لینک‌های بومی صفحه‌بندی، SSR، URL قابل اشتراک و دسترسی بدون JavaScript دارند. صفحهٔ اول URL پاک، صفحات بعد canonical و موقعیت JSON-LD مستقل دارند. شمارهٔ نامعتبر به حالت امن و شمارهٔ بیش‌ازحد به آخرین صفحه محدود می‌شود.
- Food از Sort فعلی با تساوی‌شکن شناسه استفاده می‌کند. Experience همان امتیاز شواهد قبلی را روی کاندیداهای واجد شرایط اعمال می‌کند؛ فقط hydrate کارت‌های صفحه انجام می‌شود. District اطلاعات سبک کامل را برای نقشه و آمار محلی نگه می‌دارد، نه تمام منوها.
- Review feed مستقیم از دیتابیس در درخواست SSR خوانده می‌شود؛ cache پایدار جدید ندارد. سیاست moderation و rail فعلی خانه تغییر نکردند. لینک هر نظر به Screen نظرهای همان کافه می‌رود؛ Mini App فعلی anchor اختصاصی ID نظر ندارد و در این مأموریت بازنویسی نشده است.
- هیچ Schema، dependency، قیمت، رزرو، رویداد یا دادهٔ واقعی تغییر نکرده است. TopMenu Apply اجرا نمی‌شود. نوشتن تست فقط در MariaDB disposable و دارای guard انجام شده است.

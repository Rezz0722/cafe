# فاز ۲ — قدم اول آماده‌سازی منوی شعبه

چک‌لیست در نمای کلی پنل موجود نمایش داده می‌شود؛ راهنماست و سیاست انتشار، کیفیت، قیمت و دسترسی را تغییر نمی‌دهد. شش قدم: هویت و تماس، ساعات، تصویر، دسته، آیتم موجود و قیمت عددی آیتم/گزینهٔ موجود. داده فقط از رکورد ذخیره‌شدهٔ همان شعبه و منوی مشترک خوانده می‌شود؛ بخش‌های قرنطینه یا شعبهٔ دیگر شمرده نمی‌شوند.

دکمه‌ها از `usePanelTab` موجود استفاده می‌کنند: guard تغییر ذخیره‌نشده، URL تب و back مرورگر حفظ می‌شوند. امتیاز قبلی پروفایل مستقل باقی می‌ماند. قیمت روز همچنان مجاز است؛ هشدار فقط توصیهٔ بررسی پیش از چاپ است. QR و انتشار از مسیر و سیاست فعلی استفاده می‌کنند؛ تعطیلی موقت جدا یادآوری می‌شود. هیچ checkbox خوداظهاری یا وضعیت ساختگی «QR اسکن‌شده» ذخیره نمی‌شود.

این تحویل کامل فاز ۲ نیست: پایلوت واقعی، import با preview، QR کانال و اندازه‌گیری مصرف در sprint بعد ارزیابی می‌شوند. سفارش، پرداخت یا modifier جدید ساخته نشده است. نیاز به migration ندارد. Rollback از revert PR و workflow محافظت‌شده، بدون حذف داده، انجام می‌شود.

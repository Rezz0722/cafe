# دستور اجرای پایلوت دو کافه — بدون فعال‌سازی خودکار

وضعیت آغاز: **PENDING — کافه‌ها و مسئول منو باید توسط مالک KuCafe معرفی شوند.** دورهٔ توافق‌شده ۳۰ روز رایگان است؛ شروع را هنگام تحویل واقعی و با رضایت کافه‌دار ثبت کنید. پایان دوره نباید منوی پایه یا صفحهٔ عمومی را حذف کند.

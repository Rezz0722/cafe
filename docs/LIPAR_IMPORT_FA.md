# ورود دادهٔ ساختاریافتهٔ کافه لیپار

تاریخ ورود: ۱۹ سپتامبر ۲۰۲۶

## نتیجه

- برند: `lipar-cafe` — کافه لیپار / Lipar Cafe
- شعبهٔ اول: شناسهٔ مکان `508`، slug: `lipar-cafe-branch-1`
- شعبهٔ دوم: شناسهٔ مکان `509`، slug: `lipar-cafe-branch-2`
- برای هر شعبه: ۸ دسته، ۷۳ آیتم، ۵۷ تنوعِ قیمت و ساعت کاری روزانهٔ ۰۶:۰۰ تا ۲۳:۰۰.
- قیمت‌های ورودی «هزار تومان» بودند و هنگام ورود به تومان تبدیل شدند؛ برای نمونه تونیک به‌ترتیب ۱۹۰٬۰۰۰، ۲۲۰٬۰۰۰ و ۲۵۰٬۰۰۰ تومان ثبت شده است.
- منوی هر دو شعبه در مدل داده `shared` است، ولی آیتم‌ها در scope خود هر شعبه ثبت شده‌اند؛ بنابراین صفحهٔ یک شعبه، دادهٔ کافه یا شعبهٔ دیگری را نمایش نمی‌دهد.

## وضعیت انتشار و کنترل کیفیت

هر دو شعبه فعلاً `draft` هستند، نه عمومی. علت: مختصات با برچسب تقریبی داده شده‌اند، تصویری از محیط/لوگو و شماره تماس داده نشده و چهار ردیف منو در منبع نیازمند تطبیق با منوی اصلی‌اند:

- دمنوش جوهر آبی
- دمنوش آفرینش
- دمنوش راز شب
- سردنوش مثلث سرخ

رکورد قدیمی و ناقص `کافه-لیپار` (شناسهٔ ۴۷۷، آدرس «نبش حج») هیچ منو، ساعت، عکس، نظر، ذخیره یا ادعای مالکیت نداشت و پس از گرفتن بکاپ مستقل حذف شد؛ اکنون فقط همین دو شعبهٔ لیپار وجود دارند.

## اجرای مجدد

اسکریپت idempotent است و تنها slugهای دو شعبهٔ جدید را به‌روزرسانی می‌کند:

```bash
cd /opt/kucafe
node --import tsx --conditions=react-server scripts/import-lipar.ts --dry-run
node --import tsx --conditions=react-server scripts/import-lipar.ts --apply
```

پس از تأیید موارد بالا، انتشار صریح لازم است:

```bash
node --import tsx --conditions=react-server scripts/import-lipar.ts --apply --publish
npm run build:facets
```

پیش از ورود اولیه، پشتیبان فشرده و قابل‌اعتبارسنجی در مسیر زیر ساخته شد:

`/var/backups/kucafe/lipar-import-20260919/database-before.sql.gz`

پشتیبان پیش از حذف رکورد تکراری نیز در این مسیر است:

`/var/backups/kucafe/lipar-dedupe-20260919/database-before.sql.gz`

هر اجرای موفق در `audit_log` با عنوان «ایمپورت ساختاریافتهٔ لیپار» ثبت می‌شود.

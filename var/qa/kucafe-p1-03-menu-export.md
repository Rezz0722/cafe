# KuCafe P1-03 — خروجی پایه و امن منو

تاریخ: ۱۴۰۵/۰۷/۲۳ (۲۰۲۶-۱۰-۱۵)  
شاخه: `feat/p1-03-owner-menu-export` از `origin/production` (`bc52836`)

## محدودهٔ اجرا

- مسیر دانلود خصوصی `GET /api/admin/venue/menu-export?placeId=...` افزوده شد. فقط مالک فعال همان شعبه یا ادمین واقعی مجاز است. نشست مشاهده‌به‌عنوان، مدیر شعبه، کاربر بدون مالکیت، حساب مسدود و حساب نیازمند تغییر رمز رد می‌شوند.
- خروجی JSON نسخه‌دار (`kucafe-menu`, نسخهٔ ۱) شامل دسته‌ها، آیتم‌ها، تنوع‌ها، قیمت به **تومان**، موجودی، وضعیت آرشیو و URL تصویر است. شناسه‌های داخلی، شماره تماس، اطلاعات کاربران و دادهٔ منبع خارجی در فایل نیستند. تصاویر باینری در فایل قرار نمی‌گیرند.
- فقط دسته‌های `branch` و `shared` همین شعبه صادر می‌شوند؛ دسته‌های `other_branch` و `unverified` حذف می‌شوند. آیتم آرشیوشده عمداً برای قابلیت انتقال دادهٔ کافه‌دار حفظ می‌شود.
- خواندن داده در یک تراکنش انجام می‌شود؛ پاسخ خصوصی `no-store`، `noindex` و `attachment` است. هیچ Migration یا تغییر داده لازم نیست.
- لینک دانلود با نام روشن و حالت Focus قابل‌دیدن به تب منوی پنل مالک افزوده شد؛ برای مدیر و در حالت مشاهده‌به‌عنوان نمایش داده نمی‌شود.

## شواهد آزمون

- Typecheck: موفق، پس از آخرین اصلاح.
- تست‌های واحد هدفمند: ۷ موفق، ۰ شکست.
- تست Integration روی MariaDB 11.4 ایزوله با Schema مهاجرت‌یافته: ۱ موفق، ۰ شکست؛ جداسازی شعبه، لغو نقش، تنوع قیمت، آرشیو، حفظ زمان قیمت و عدم تغییر ردیف‌ها بررسی شد. کانتینر آزمایشی پس از آزمون حذف شد.
- مجموعهٔ کامل تست‌ها: ۴۵۴ موفق، ۰ شکست، ۷ Skipped؛ تست Integration پرچم‌دار جداگانه اجرا شد.
- Build ایزولهٔ Next.js: موفق؛ مسیر API در خروجی حاضر بود. خروجی موقت Build پس از آزمون حذف شد، بدون تغییر فایل‌های سرویس زنده.
- `git diff --check`: موفق.

## محدودیت و انتشار

- Import مستقیم همین JSON و Round-trip در P1-06 است؛ خروجی فعلی را نباید به‌عنوان فایل قابل‌Import فوری معرفی کرد.
- فایل فقط لینک تصویر دارد؛ برای نگهداری مستقل تصویر، دانلود یا Export رسانه در فاز جدا لازم است.
- آزمون HTTP با نشست واقعی مالک روی Production انجام نشده است؛ این کار پس از Merge/Deploy مجاز و با حساب آزمایشی معتبر باید Smoke شود.
- هیچ Merge، Deploy، Migration یا TopMenu Apply روی Production انجام نشده است. CI نهایی PR باید سبز شود و انتشار نیازمند مجوز مالک است.

## Rollback

چون Schema و داده تغییر نمی‌کنند، Rollback برنامه به Image قبل از P1-03 کافی است؛ فایل خروجی قبلاً دانلودشده در دستگاه کاربر باقی می‌ماند.
